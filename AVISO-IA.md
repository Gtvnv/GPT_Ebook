# Aviso de Inteligência Artificial

## Uso de IA neste projeto

O conteúdo deste repositório e do e-book foi **gerado com apoio de ferramentas de inteligência artificial (IA)**. Isso inclui os textos dos capítulos, os exemplos de código CSS e as descrições de imagens.

## Revisão humana

Todo o conteúdo gerado passou por **revisão humana** antes da publicação, seguindo o [Checklist de Revisão](CHECKLIST-REVISAO.md). A revisão reduz erros, mas não os elimina por completo.

## Possíveis imprecisões

Mesmo após a revisão, o material **pode conter imprecisões**, como:

- informações técnicas desatualizadas ou incompletas;
- exemplos de código que se comportam de forma diferente em outros navegadores ou versões;
- erros de texto, gramática ou interpretação.

Teste os exemplos em seu próprio ambiente e consulte a documentação oficial (por exemplo, MDN Web Docs) para confirmar as informações importantes.

## Como relatar problemas

Se encontrar um erro ou uma imprecisão, abra uma issue ou proponha uma correção conforme o [guia de contribuição](CONTRIBUTING.md).
