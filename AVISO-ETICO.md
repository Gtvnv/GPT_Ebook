# Aviso Ético

Este documento descreve as diretrizes éticas adotadas neste projeto.

## Transparência sobre o uso de IA

O projeto utiliza ferramentas de inteligência artificial para apoiar a criação de textos, exemplos de código e descrições de imagens. O uso de IA é declarado de forma aberta. Detalhes estão no [Aviso de IA](AVISO-IA.md). O conteúdo gerado é revisado por uma pessoa antes da publicação.

## Respeito a direitos autorais

- O projeto busca produzir conteúdo próprio e não reproduzir textos, códigos ou imagens protegidos por direitos autorais de terceiros.
- Os prompts de imagem evitam nomes de personagens, logotipos e marcas protegidos, preferindo descrições genéricas inspiradas em ficção científica espacial.
- Contribuições não devem incluir material protegido sem autorização.
- O repositório que inspirou a estrutura inicial é citado apenas como inspiração, no [README](README.md).

## Marcas de terceiros: Star Wars

"Star Wars" e os nomes, personagens, logotipos e elementos associados são marcas e propriedades de seus respectivos detentores de direitos. A referência ao tema neste projeto serve apenas como ambientação temática para ensinar CSS.

**Este projeto não possui afiliação, patrocínio, aprovação ou endosso dos detentores dos direitos de Star Wars.** Ele é uma iniciativa independente, sem qualquer vínculo oficial com essas empresas ou com seus representantes.

## Ausência de dados pessoais nos prompts

Os prompts e o conteúdo do repositório não contêm dados pessoais, segredos, chaves de API ou credenciais. Contribuidores não devem incluir esse tipo de informação em prompts, exemplos ou arquivos.

## Finalidade educacional

O projeto tem finalidade exclusivamente educacional e sem fins comerciais diretos: ensinar CSS de forma didática e demonstrar um fluxo reproduzível de criação de e-book com apoio de IA.
